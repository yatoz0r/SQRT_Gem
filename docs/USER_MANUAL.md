## 1. Назначение и целевая аудитория

Программный продукт **«Калькулятор высокой точности» (SQRT_Gem)** предназначен для выполнения прецизионных математических вычислений произвольной разрядности с управляемой точностью отображения и расчета. 

Приложение спроектировано как для повседневных вычислений, так и для сложных инженерных, научно-исследовательских и академических задач, где стандартные типы с плавающей точкой (`float64` / IEEE 754) приводят к катастрофической потере точности из-за ошибок округления.

### Целевые группы пользователей:
1. **Обычный пользователь**: проведение бытовых и учебных расчетов с наглядным графическим интерфейсом и мгновенной реакцией.
2. **Технический специалист / Исследователь**: расчет сверхдлинных чисел (от 1000+ десятичных знаков), точное извлечение корней, вычисление трансцендентных функций и констант ($\pi$, $e$) с гарантированной математической воспроизводимостью.
3. **Системный администратор / Инженер внедрения**: развертывание приложения на парке ПК, автоматизированная тихая установка, переносимость (Portable) и бесследное удаление.
4. **Специалист технической поддержки**: использование встроенного центра самодиагностики, экспресс-анализ инцидентов и сбор стандартизированных отчетов.

## 2. Системные требования и поддерживаемые платформы

Приложение официально верифицировано и поддерживается на следующих операционных системах:

| Платформа | Архитектура | Минимальная версия ОС | Системные зависимости |
| :--- | :--- | :--- | :--- |
| **Microsoft Windows** | x86-64 | Windows 10 (билд 1809+) / Windows 11 | Visual C++ Redistributable 2015–2022 |
| **Linux** | x86-64 | Ubuntu 20.04+ LTS, Debian 11+, Fedora 36+ | `glibc` 2.31+, `libxcb`, `libxkbcommon` |
| **Apple macOS** *(опционально)* | Apple Silicon (arm64) / Intel (x64) | macOS 12 (Monterey) и новее | Стандартная системная среда |

**Минимальные аппаратные требования:**
- Процессор: 64-битный двухъядерный CPU с частотой от 1.6 ГГц.
- Оперативная память: 512 МБ RAM.
- Дисковое пространство: 85 МБ свободного места на носителе.
- Дисплей: разрешение от 1024×768 пикселей.

## 3. Установка, обновление и удаление

### 3.1. Установка в ОС Windows

#### Вариант А: Нативный Windows Installer (`SQRT_Gem.msi`) — Рекомендуется
1. Запустите `SQRT_Gem.msi`.
2. Windows Installer выполнит регистрацию компонентов, создаст ярлыки в меню «Пуск» и на Рабочем столе.
3. **Корпоративная тихая установка (для администраторов):**
   ```cmd
   msiexec /i SQRT_Gem.msi /passive /norestart
   ```
4. **Тихое удаление:**
   ```cmd
   msiexec /x SQRT_Gem.msi /quiet
   ```

#### Вариант Б: Стандартный установщик Inno Setup (`SQRT_Gem_Setup_v1.0.0.exe`)
1. Запустите `SQRT_Gem_Setup_v1.0.0.exe`.
2. Следуйте указаниям мастера установки и выберите создание ярлыков.

#### Вариант В: Портативная версия (Portable `.zip`)
1. Распакуйте архив `SQRT_Gem_v1.0.0_win64_portable.zip`.
2. Запустите `SQRT_Gem.exe`. Конфигурация сохраняется в локальной папке данных пользователя.

---

### 3.2. Установка в Linux

#### Вариант А: Официальный Debian-пакет (`sqrt-gem_1.0.0_amd64.deb`)
1. Установите пакет системным менеджером:
   ```bash
   sudo apt install ./sqrt-gem_1.0.0_amd64.deb
   ```
2. Приложение автоматически зарегистрирует desktop-файл, иконку в системной теме и команду `sqrt-gem` в `/usr/bin`.
3. Запуск осуществляется из панели приложений «Наука / Математика» или командой `sqrt-gem`.

#### Вариант Б: Установка через пользовательский скрипт
```bash
./packaging/install.sh
```

---

### 3.3. Обновление программы
Приложение оснащено модулем бесшовного обновления:
- **В среде Windows Installer (MSI):** установка новой версии MSI поверх старой автоматически обновляет бинарные файлы с сохранением конфигурации и истории вычислений.
- **В среде Linux (.deb):** обновление выполняется стандартно через `sudo apt install ./sqrt-gem_<new_version>_amd64.deb`.
- **Встроенное обновление в приложении:** в диалоге «Проверить обновления» можно напрямую скачать и установить последнюю совместимую версию в один клик.

---

### 3.4. Удаление программы
- **В Windows:** через «Установка и удаление программ» (Панель управления) или через команду `msiexec /x SQRT_Gem.msi`.
- **В Linux (Debian/Ubuntu):**
  - Удаление приложения с сохранением настроек:
    ```bash
    sudo apt remove sqrt-gem
    ```
  - Полное удаление программы и пользовательских настроек/истории:
    ```bash
    sudo apt purge sqrt-gem
    ```

## 4. Первый запуск и интерфейс программы

Главное окно приложения разделено на 4 вкладки:
1. **Калькулятор**: строка ввода выражения, клавиатура быстрого ввода, селектор точности (0..1000 знаков), поле результата, метрики времени и количества цифр, кнопка копирования.
2. **История**: таблица последних операций (дата, выражение, точность, результат), кнопки копирования, повторного вызова, экспорта в CSV/JSON и очистки.
3. **Настройки**: динамический выбор языка (RU, EN, ES, ZH), темы оформления, точности по умолчанию, автопроверки обновлений.
4. **Диагностика**: Центр самодиагностики и самообслуживания (запуск тестов здоровья, экспорт zip-архива для поддержки, сброс к заводским настройкам, FAQ).

## 6. Примеры практического использования

- **Базовый квадратный корень:** `sqrt(144)` -> `12`
- **Составное выражение:** `(15.5 + 2.75) * sqrt(144)` -> `219.00`
- **Иррациональное число (50 знаков):** `sqrt(2)` -> `1.41421356237309504880168872420969807856967187537695`
- **Сверхдлинное деление:** `123456789012345678901234567890 / 987654321`

## 7. Разграничение понятий точности

1. **Точность хранения:** Числа в промежуточных вычислениях хранятся как объекты `Decimal` без перехода к ограниченным машинным типам.
2. **Точность вычислений:** Динамический контекст расширяется на **+10 защитных разрядов (Guard Digits)** для предотвращения накопленной погрешности.
3. **Точность отображения:** Округление финального числа методом `ROUND_HALF_UP` строго до выбранного пользователем количества знаков (от 0 до 1000).
